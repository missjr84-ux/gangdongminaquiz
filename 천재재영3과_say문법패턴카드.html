뼈대가 되는 문법 패턴

📖 Say Goodbye to Stress · 핵심 패턴 16개 · 탭하면 정답 + 🔊 발음 듣기

😨 Mina (15, 대전) — S01~S11
1
to부정사 — 부사적(목적)~하기 위해
Others eat special foods
to feel better.
다른 사람들은 기분이 좋아지도록 특별한 음식을 먹는다.
👆 단어 탭 → 정답 공개
Others eat special foods to feel better.
~하기 위해 (목적)
= to + 동사원형 (부사적 용법)
📌 S02 원문! = in order to feel better
2
so + 형용사 + that + S + V너무 ~해서 …하다
Good horror movies are
so scary that
I scream a lot.
좋은 공포 영화는 너무 무서워서 나는 소리를 많이 지른다.
👆 단어 탭 → 정답 공개
Good horror movies are so scary that I scream a lot.
너무 ~해서 …하다.
= so + 형용사/부사 + that + 결과절
📌 S08 원문! 수능 빈출 결과 구문
3
help + 목적어 + (to) 동사원형~가 …하도록 돕다
Screaming helps me
feel better.
있는 힘껏 소리를 지르는 것이 기분이 나아지게 하는 데 도움이 된다.
👆 단어 탭 → 정답 공개
Screaming helps me feel better.
~가 …하도록 돕다.
= help + 목적어 + (to) 동사원형
📌 S09 응용! to 있어도 없어도 OK
4
by + 동명사(-ing)~함으로써
My friends give me stress
by saying bad things about me.
내 친구들은 나에 관해 나쁜 말을 함으로써 스트레스를 준다.
👆 단어 탭 → 정답 공개
My friends give me stress by saying bad things about me.
~함으로써 (수단·방법)
= by + 동명사(-ing)
📌 S06 원문! saying/breaking/arguing 병렬
🎣 Junho (14, 여수) — S11~S18
5
have been + -ing현재완료진행
I have been using
this method for the past several months.
나는 지난 몇 달 간 이 방법을 써 오고 있다.
👆 단어 탭 → 정답 공개
I have been using this method for the past several months.
~해 오고 있다. (과거~현재 계속)
= have/has been + 동사원형-ing
📌 S11 원문! for/since와 함께 출제
6
try + to 동사원형~하려고 노력하다
He always tries to be
positive by going fishing.
그는 낚시를 다니며 항상 긍정적으로 지내려고 노력한다.
👆 단어 탭 → 정답 공개
He always tries to be positive by going fishing.
~하려고 노력하다.
= try + to 동사원형
📌 S14 원문! ⚠️ try + -ing(시험 삼아) 구별!
7
so ~ that = enough to결과 / 정도
I'm so focused
that I can leave all my worries behind.
나는 너무 집중해서 모든 걱정을 잊을 수 있다.
👆 단어 탭 → 정답 공개
I'm so focused that I can leave all my worries behind.
너무 ~해서 …하다.
= so + 형용사 + that + S + can + V
📌 S16 원문! = focused enough to leave ~ (변환 가능)
8
teach + 목적어 + to 동사원형5형식
Besides, it teaches me
to be patient.
게다가, 그것은 나에게 인내심 갖는 법을 가르쳐 준다.
👆 단어 탭 → 정답 공개
It teaches me to be patient.
~가 …하도록 가르치다.
= teach + 목적어 + to 동사원형 (5형식)
📌 S17 원문! want/tell/ask/expect 모두 동일 패턴
🧹 Dobin (16, 서울) — S19~S24
9
명사 + to 동사원형 (형용사적)~할 (명사)
My sister has a wonderful way
to stay free from stress.
우리 누나는 스트레스에서 벗어나는 훌륭한 방법이 있다.
👆 단어 탭 → 정답 공개
My sister has a wonderful way to stay free from stress.
~할 (명사) — 형용사적 용법
= 명사 + to 동사원형
📌 S19 원문! way/time/place to V 패턴 암기
10
It is because + 절그것은 ~이기 때문이다
It is because
cleaning is my sister's number-one way to make life better!
그것은 청소가 삶을 더 좋게 만드는 그녀의 최고의 방법이기 때문이다!
👆 단어 탭 → 정답 공개
It is because cleaning is my sister's number-one way to make life better!
그것은 ~이기 때문이다.
= It is because + 주어 + 동사
📌 S21 원문! ⚠️ It is because(이유) vs It is that(강조구문) 구별!
11
seem + to 동사원형~인 것 같다
My mother seems to like
the situation for a good reason.
엄마는 합당한 이유로 그 상황을 좋아하는 것 같다.
👆 단어 탭 → 정답 공개
My mother seems to like the situation for a good reason.
~인 것 같다.
= seem + to 동사원형 (= It seems that ~)
📌 S20 원문!
12
feel like + 주어 + 동사~한 느낌이 들다
As I clean my room,
I feel like
I'm also relieving stress.
방을 청소할 때, 나는 스트레스도 풀리는 느낌이 든다.
👆 단어 탭 → 정답 공개
I feel like I'm also relieving stress.
~한 느낌이 들다.
= feel like + 주어 + 동사
📌 S23 원문! cf. feel like + -ing = ~하고 싶다 (의미 다름!)
📅 Yulia (14, 안산) + 마무리 — S25~S33
13
let + 목적어 + 동사원형사역동사
Let me tell you
what my mother does about her stress.
우리 어머니가 스트레스를 어떻게 다루는지 말해줄게.
👆 단어 탭 → 정답 공개
Let me tell you what my mother does about her stress.
~가 …하게 허락하다 (사역동사)
= let + 목적어 + 동사원형 (to 절대 불가!)
📌 S25 원문! make/let/have → 원형, want/tell/ask → to V
14
have been + -ing + for현재완료진행
I have been writing
'Me Time' on my calendar for two months.
나는 두 달째 달력에 '나만의 시간'을 적어 오고 있다.
👆 단어 탭 → 정답 공개
I have been writing 'Me Time' on my calendar for two months.
~해 오고 있다 (지금도 계속 중)
= have/has been + 동사원형-ing
📌 S31 원문! feel much better — 비교급 강조 부사
15
as long as + S + V~하기만 하면
It doesn't really matter what I do,
as long as it's something I like.
내가 좋아하는 것이기만 하면, 내가 무엇을 하든 별로 중요하지 않다.
👆 단어 탭 → 정답 공개
It doesn't really matter what I do, as long as it's something I like.
~하기만 하면 (조건)
= as long as + 주어 + 동사
📌 S30 원문!
16
find + 명사 + to 동사원형형용사적 용법
Find your best way
to say goodbye to stress.
스트레스와 이별하는 자신만의 최선의 방법을 찾아라.
👆 단어 탭 → 정답 공개
Find your best way to say goodbye to stress.
~할 (방법) — 형용사적 용법
= 명사 + to 동사원형 (명사 수식)
📌 S33 원문! say goodbye to = ~와 이별하다
💡
⚠️ 핵심 혼동 포인트!
✔ try + to V(노력) vs try + -ing(시험 삼아) — S14
✔ let/make/have + 목적어 + 원형 vs want/tell/teach + 목적어 + to V
✔ have been + -ing — S11, S13, S31 세 번 등장 → 수능 단골
✔ so ~ that ↔ enough to 변환 (S08, S16 서술형 출제)
✔ feel like + S+V(느낌이 들다) vs feel like + -ing(~하고 싶다)
