뼈대가 되는 문법 패턴

🐋 I Love Humpback Whales · 핵심 패턴 16개 · 탭하면 정답 + 🔊 발음 듣기

📚 본문 핵심 패턴 (S01–S28)
1
used to + 동사원형과거 습관
I used to keep
a diary about them.
나는 그들에 관한 일기를 써 왔다.
👆 단어 탭 → 정답 공개
I used to keep a diary about them.
예전에 ~하곤 했다.
= used to + 동사원형
📌 본문 응용 / ⚠️ be used to + -ing(익숙하다)와 구별!
2
be used to + 명사/동명사익숙함
Nikau is used to
observing humpback whales.
Nikau는 혹등고래를 관찰하는 것에 익숙하다.
👆 단어 탭 → 정답 공개
Nikau is used to observing humpback whales.
~에 익숙하다.
= be used to + 명사/동명사(-ing)
📌 used to + V(원형) = 과거 습관 — 혼동 주의!
3
so ~ that + S + V너무 ~해서 …하다
There were so many plastic bags that
they filled its stomach.
너무 많은 비닐봉지가 있어서 고래의 위를 가득 채웠다.
👆 단어 탭 → 정답 공개
There were so many plastic bags that they filled its stomach.
너무 ~해서 …하다.
= so + 형용사/부사 + that + 결과절
📌 S25 응용 — 수능 빈출 결과 구문
4
not only A but also BA뿐만 아니라 B도
Humpback whales not only
sing beautiful songs but also
save other animals.
혹등고래는 노래를 부를 뿐만 아니라 다른 동물을 구하기도 한다.
👆 단어 탭 → 정답 공개
Humpback whales not only sing beautiful songs but also save other animals.
A뿐만 아니라 B도.
= not only A but also B
📌 S23 응용
5
want + 목적어 + to 동사원형5형식
I want humans and sea animals to live
in harmony.
나는 인간들과 바다 동물들이 조화롭게 살기를 원한다.
👆 단어 탭 → 정답 공개
I want humans and sea animals to live in harmony.
~가 …하기를 원하다.
= want + 목적어 + to 동사원형
📌 S28 원문! 수능 5형식 단골
6
expect + 목적어 + to 동사원형5형식
I never expected
them to save my life.
나는 그들이 내 생명을 구해줄 것이라고는 전혀 기대하지 않았다.
👆 단어 탭 → 정답 공개
I never expected them to save my life.
~가 …할 것을 기대하다.
= expect + 목적어 + to 동사원형
📌 S23 원문!
7
the 비교급, the 비교급비례 강조
The more data Nikau collects,
the better he understands whales.
더 많은 데이터를 모을수록, 고래를 더 잘 이해한다.
👆 단어 탭 → 정답 공개
The more data Nikau collects, the better he understands whales.
더 ~할수록 더 …하다.
= the + 비교급 + S+V, the + 비교급 + S+V
📌 S12 응용
8
the + 최상급최상급
Human activities are
the greatest danger to whales.
인간 활동은 고래에게 가장 큰 위험이다.
👆 단어 탭 → 정답 공개
Human activities are the greatest danger to whales.
가장 ~한 …이다.
= the + 최상급 + 명사
📌 S26 원문!
💬 대화문 핵심 패턴 (Oliver · T-shirt · Animals)
9
used to + 동사원형과거 습관
I used to feel that way, too.
나도 예전엔 그런 기분을 느끼곤 했어.
👆 단어 탭 → 정답 공개
I used to feel that way, too.
예전에 ~하곤 했다.
= used to + 동사원형
📌 Oliver & Mom 원문!
10
so that + S + can/could목적
Oliver studied hard so that
he could pass the test.
Oliver는 시험에 합격하기 위해 열심히 공부했다.
👆 단어 탭 → 정답 공개
Oliver studied hard so that he could pass the test.
~하기 위해 (목적)
= so that + 주어 + can/could + 동사원형
📌 대화 응용
11
not A but BA가 아니라 B
Stress was not harmful
but helpful for Oliver's mom.
스트레스는 해로운 것이 아니라 도움이 되었다.
👆 단어 탭 → 정답 공개
Stress was not harmful but helpful for Oliver's mom.
A가 아니라 B이다.
= not A but B
📌 대화 응용
12
make + 목적어 + 동사원형사역동사
Stress made me
focus and try harder.
스트레스는 나를 집중하고 더 열심히 노력하게 만들었다.
👆 단어 탭 → 정답 공개
Stress made me focus and try harder.
~가 …하게 만들다.
= make + 목적어 + 동사원형 (to 없음!)
📌 Oliver & Mom 원문!
13
have to + 동사원형의무
We have to
choose a T-shirt with short sleeves.
우리는 반팔 티셔츠를 선택해야 한다.
👆 단어 탭 → 정답 공개
We have to choose a T-shirt with short sleeves.
~해야 한다. (의무)
= have to + 동사원형 (= must)
📌 T-shirt 대화 원문!
14
What makes you say that?이유 요청
B2: We have to choose short sleeves.
B1: What makes you say that?
왜 그렇게 생각해?
👆 단어 탭 → 정답 공개
What makes you say that?
왜 그렇게 생각해? (이유 묻기)
= What makes + 주어 + 동사원형?
📌 T-shirt / Oliver 공통 원문!
15
so + 형용사 + that결과절
The bee on the T-shirt
is so cute that everyone loves it.
티셔츠의 벌이 너무 귀여워서 모두가 좋아한다.
👆 단어 탭 → 정답 공개
The bee is so cute that everyone loves it.
너무 ~해서 …하다.
= so + 형용사 + that + 결과절
📌 T-shirt 대화 응용
16
It is + 형용사 + for + 사람 + to V가주어 it
It is surprising for horses to sleep on their feet.
말이 서서 잠을 잔다는 것은 놀랍다.
👆 단어 탭 → 정답 공개
It is surprising for horses to sleep on their feet.
누가 ~하는 것은 …하다.
= It is + 형용사 + for + 사람/동물 + to 동사원형
