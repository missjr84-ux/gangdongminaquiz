# print — 완성 인쇄물 보관

만든 시험지·강의안·교재(docx·pptx·xlsx·pdf)를 여기에 넣습니다.

## 왜 넣나

대화가 끝나면 그 대화에서 만든 파일은 대화 안에만 남습니다.
다음에 "그 시험지 좀 고쳐 줘" 하면 대화를 찾아서 코드를 다시 돌려야 합니다.

여기 올려두면 어느 대화에서든 바로 꺼내서 고칠 수 있습니다.

## 어디에 넣나

| 폴더 | 들어가는 것 |
|---|---|
| `중고등/` | 교과서 단원노트, 문법 시험지·단원평가, 수업 PPT·강의안, 내신 변형 |
| `모의고사/` | 학평 해설지·해석지·강의안, 단어장, 어법·독해 유형 |
| `초등/` | 파닉스 교재, 어휘 학습지, 방탈출 인쇄물 |
| `운영/` | 시간표, 진도표, 보고서, 학부모 안내문 |

## 파일 이름

`[날짜]_[과정]_[단원]_[종류].확장자`

```
20261126_중1능률_7-8과_문법종합평가.docx
20261126_중1능률_7-8과_문법종합평가_정답.docx
20261125_고1_가정법_수업.pptx
20261122_운영_2027중2_연간스케줄.docx
```

- 날짜는 만든 날. 같은 자료를 고치면 새 날짜로 올리고 이전 것도 둡니다.
- 정답지는 같은 이름에 `_정답`만 붙입니다. 학생용과 나란히 보입니다.
- 한글 파일명을 씁니다. 깃허브에서 그대로 보입니다.

## 올리는 방법

깃허브 웹에서 폴더를 열고 `Add file` → `Upload files` → 끌어다 놓기 → `Commit changes`.
