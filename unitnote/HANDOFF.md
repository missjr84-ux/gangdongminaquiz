# 단원노트 제작 — 인수인계

강동미나 중고등부 교과서 **단원노트**(한글노트 형식 PPT + 엑셀)를 만드는 도구예요.
새 세션에서는 이 문서만 읽고 바로 이어서 만들 수 있게 정리했어요.

새 세션에 이렇게 말하면 돼요:
> 레포 missjr84-ux/gangdongminaquiz 의 unitnote/HANDOFF.md 읽고, ○○ ○과 단원노트 만들어 줘

---

## 1. 결과물 (한 단원당 3개)

| 파일 | 내용 |
|---|---|
| `{학년_출판사_단원}_단원노트.pptx` | 학생용. A4 세로, 수정 가능한 PPT |
| `{학년_출판사_단원}_단원노트_정답.pptx` | 선생님용 정답. 학생용과 따로 |
| `{학년_출판사_단원}_단원노트.xlsx` | 같은 내용을 엑셀로. 학생 시트 + `정답_` 시트 |

학생용 노트 순서 (표지에 쪽 번호 목차가 자동으로 들어가요)

| 순서 | 섹션 | 하는 일 |
|---|---|---|
| 1 | 단어 노트 | 왼쪽에 영단어, 뜻·유의어(=)·반의어(↔) 칸. 짝이 없는 칸은 학생용에 회색 "없음", 정답에 "—". 한 쪽에 15개 |
| 2 | 숙어 노트 | 단어와 같은 형식. 15개가 넘으면 반씩 나눠요 |
| 3 | 영영풀이 노트 | 영영풀이를 쓰고 그 아래 해석 줄 |
| 4 | 핵심문법 1·2 | 공식 상자 → 개념 빈칸 채우기 → 서술형 영작 10문제(주어진 말 포함) |
| 5 | 본문 구문 분석 + 해석 | 영어 한 줄 + 해석 줄. 안내: "직접 구문 분석 + 해석 하세요" |
| 6 | 본문 거꾸로 영작 | 한글만 주고 영어 쓰기. 핵심 표현은 밑줄 + "형광펜 칠하기" 안내 |

정답 PPT는 단어·숙어·영영풀이·문법 정답과, 본문 끊어 읽기(/)·해석·포인트(핵심 표현 굵은 밑줄)가 들어가요. 거꾸로 영작 답도 여기서 같이 봐요.

## 2. 폴더 구조

| 경로 | 역할 |
|---|---|
| `make.sh` | **한 단원 전체 만들기**: `bash make.sh festivals` → `out/festivals/` |
| `render.sh` | 미리보기 PNG(8쪽씩 한 장): `bash render.sh out/festivals` |
| `extract.py` | 레포의 인터랙션 html에서 데이터(json)를 꺼내요 |
| `build.js` | PPT 생성기 (pptxgenjs) — 디자인·쪽 나누기 전부 여기 |
| `fixppt.py` | PPT 후처리 (아래 4번 함정 참고). make.sh가 자동 실행 |
| `xl.py` | 엑셀 생성기 (openpyxl) |
| `mk_common.py`, `keys.py` | 단원 스크립트가 쓰는 공용 함수 (W·D·G·save, 본문 읽기) |
| `units/mk_<단원>.py` | **단원마다 하나** — 단어·숙어·영영풀이·핵심 표현·문법을 여기 적어요 |
| `src/` | 레포 html에서 꺼낸 원본 json (본문·단어) |
| `data/data_<단원>.json` | mk 스크립트가 만든 최종 데이터 → build.js·xl.py가 읽어요 |
| `fonts/` | 주아(Jua) 폰트 + 라이선스(OFL) |

`out/`은 git에 안 올려요(.gitignore). 필요할 때 make.sh로 다시 만들면 돼요.

## 3. 새 단원 만드는 순서

1. **원본 꺼내기** — 레포에 그 단원 인터랙션이 있으면:
   ```bash
   cd unitnote
   python3 extract.py ../○○reading.html src/○○reading.json
   ```
   - 예전 엔진(`window.DATA=`)이면 본문 탭의 `analysis` 블록에 문장별 en·kr·끊어 읽기(ch)·tip이 있어요 → `rows_with_keys()`로 바로 읽어요 (`mk_heroes.py` 참고)
   - 새 엔진(`var CFG=`, 동아 7과 festivals)이면 거꾸로 영작 qset(한글 q, 영어 a) + 어순 배열 qset(c = 끊어 읽기) + 한글 분석 탭의 `class="rp"` 포인트를 짝지어요 (`mk_festivals.py` 참고)
   - 레포에 없으면 교과서 PDF·사진을 받아서 직접 적어요
2. **단원 스크립트 만들기** — 가장 비슷한 `units/mk_*.py`를 복사해서 고쳐요
   - `words = W([("단어", "뜻", "유의어", "반의어"), ...])` — 유의어·반의어 없으면 빈칸
   - `idioms = W([...])` 같은 형식
   - `defs = D([("단어", "영영풀이", "해석"), ...])` — 보통 15개
   - `KEY = {문장번호: [("한글 핵심 표현", "영어 핵심 표현"), ...]}` — **한글·영어 문장에 글자 그대로 들어 있어야 해요** (assert로 검사)
   - `grammar = [G(제목, "핵심문법 1", 공식, 개념목록, 영작10개), ...]` — 개념의 `[ ]` 안이 학생용 빈칸이 돼요. 영작은 정확히 10개
   - `save(os.path.join(ROOT, "data", "data_<단원>.json"), acad="강동미나 중고등부 · 중N 출판사(저자)", words=..., idioms=..., defs=..., rows=..., grammar=...)`
   - 본문이 없으면 `rows=[]` → 본문 섹션이 자동으로 빠져요 (`mk_l8.py`)
   - 교과서 단어가 아니라 본문에서 뽑은 단어면 `wordNoteAns="정답 — 본문에서 뽑은 단어예요 ..."` 추가 (`mk_poem.py`)
3. **make.sh에 한 줄 추가** — `case` 안에 `키) L="Lesson N  제목"; F="중N_출판사_N과" ;;` (Lesson과 제목 사이 **공백 두 칸** → 표지에서 두 줄로 나뉨)
4. `bash make.sh <키>` → `bash render.sh out/<키>` → PNG를 직접 보고 검사(5번)
5. 결과 파일 3개를 준에게 보내요. 짧게 — 무엇이 들어갔는지 표 하나 + 확인할 점만

## 4. 알려진 함정 (이미 고쳐 둔 것)

| 증상 | 원인 | 처리 |
|---|---|---|
| 한글이 주아로 나오거나 줄 서식이 깨짐 | pptxgenjs가 한 문단에 `<a:pPr>`를 여러 번 넣음 | `fixppt.py`가 첫 번째만 남김. 모든 run에 fontFace BODY 지정 |
| 머리글 ↔ 기호가 안 보임 | 주아에 ↔ 글자가 없음 | "(=)" "(↔)"만 본문 폰트로 |
| 정답 끊어 읽기에서 글자가 빠짐 ("Let's shar") | 따옴표 때문에 덩어리 위치가 밀림 | `slashRuns`가 덩어리를 문장에서 직접 찾아 자름 |
| 쪽 맨 아래에 문단 제목만 남음 | 제목 다음 내용이 다음 쪽으로 | `keepNext` — 제목은 다음 항목과 같이 넘어가요 |
| 마지막 쪽에 단어 2개만 남음 | 15개씩 나누고 남은 것 | 단어 수를 15의 배수 근처로 조정 (동아 7과: 사소한 단어 2개 뺌) |
| 미리보기 글자가 원본과 다름 | 컨테이너에 맑은 고딕·주아가 없음 | `cp fonts/Jua-Regular.ttf ~/.fonts/ && fc-cache -f`. 맑은 고딕은 Noto Sans CJK KR로 대체돼 보여요 (준 컴퓨터에선 정상) |

## 6. 준이 정한 규칙

- 한글 제목·라벨 폰트는 **주아(Jua)** 고정, 본문은 맑은 고딕
- 학원 표기는 **"강동미나 중고등부"** (뮤엠 표기 금지 — 초등부 전용)
- 흑백 출력 → 색 강조 대신 굵게·밑줄. **진한 색 채운 헤더 상자 금지**, 제목에 ①②③ 같은 동그라미 번호 금지
- 글자 11~12pt 이상, 쓰는 줄은 넉넉하게
- 정답은 항상 문제와 따로
- 안내 문구는 존댓말 해요체 ("~하세요", "~예요"). "~한다/~이다" 문어체 금지
- 수정 가능한 형식(PPT·엑셀)으로
- 결과는 간단하게 — 파일 많이, 긴 설명 X
